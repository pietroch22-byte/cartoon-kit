# Modelli 3D CC0 (Kenney) per la via 4 della scala: 3D → sprite 2D

Archivi per categoria (limite skill 200 file: ogni nuovo kit va in un archivio, mai file sciolti). Licenza CC0, uso commerciale libero. Estrai con `unzip -o library/modelli3d/kenney-food.zip -d work/modelli`. Per usarli nel 2D: render una volta in vista frontale o 3/4 con ombreggiatura piatta 2-3 toni + contorno #1E1E24, salva PNG in `library/sprite/<id>.png` e aggiungi la voce al manifest con fonte "sprite3d".
